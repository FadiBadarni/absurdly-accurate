Privacy Policy

Effective 4 November 2026

This policy covers the Absurdly Accurate channel tool: a private program the owner of the Absurdly Accurate YouTube channel runs on their own computer to manage that channel. It is not offered to the public, and the only Google account that signs in to it is the channel owner's.

What it accesses

When the channel owner signs in with Google and grants access, the tool uses the YouTube Data API to:

  • read the channel's name, handle, statistics, description and list of uploaded videos;
  • upload videos and set their titles, descriptions, tags, audience setting and thumbnails;
  • update the channel's description, keywords and banner;
  • delete videos from the channel when the owner asks for it.

It does not access any other account, any viewer's data, or any Google data beyond the owner's YouTube channel.

Storage and sharing

  • The sign-in token is stored only on the channel owner's computer. There is no server, database or cloud copy.
  • No data is sold, shared with third parties or used for advertising. Data goes only between the owner's computer and Google's YouTube API.
  • This website sets no cookies and runs no analytics.

Removing access

Access can be revoked at any time from Google Account permissions. Deleting the token file on the owner's computer also removes the tool's stored access.

YouTube API Services

This tool uses YouTube API Services. By using it you agree to the YouTube Terms of Service, and Google's handling of data is described in the Google Privacy Policy.
